# EUROCOM — концепт редизайна

Концепт нового сайта для [eurocom.in](https://eurocom.in) от студии ИНАЧЕ. Статический сайт без сборки: открывается через GitHub Pages.

## Страницы

| Файл | Раздел |
|---|---|
| `index.html` | Главная: первый экран с видео |
| `products.html` | Продукция: шкала марок SMART INT, карточка марки, расчёт дозировки, сравнение |
| `applications.html` | Применение: вкладки по технологиям (плёнка, трубы, выдув, литьё) |
| `company.html` | Компания: производство, качество и документы, площадки |
| `price.html` | Запрос прайс-листа (поддерживает `?grade=2905`) |
| `contacts.html` | Контакты и форма обратной связи |

Общие стили и скрипт: `assets/site.css`, `assets/site.js`.

## Что в демо не подключено

- Формы не отправляют данные — показывают уведомление.
- PDF-документы и мессенджеры — заглушки.
- ПТР и фасовка помечены «по TDS» — нужны данные клиента.
- Фоновое видео загружается со стороннего CDN; для рабочей версии нужен собственный ролик.
